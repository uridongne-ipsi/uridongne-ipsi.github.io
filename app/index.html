플레이스토어에서 설치하기

버튼이 열리지 않으면 플레이스토어에서 우리동네 입시연구소를 검색해 주세요.

지금은 카톡·네이버 앱 안에서 열려 있어요

앱 안의 화면에서는 홈 화면에 추가할 수 없어요. Safari로 이 페이지를 다시 열어 주세요.

Safari로 열기

오른쪽 아래(또는 위)의 버튼을 누르고 다른 브라우저로 열기 또는 Safari로 열기를 고르세요.

메뉴가 안 보이면 주소를 복사한 뒤 Safari를 열어 주소창에 붙여넣으세요.

아이폰은 홈 화면에 추가해서 써요

아이폰은 앱스토어 대신 Safari에서 홈 화면에 추가하면, 안드로이드 앱과 같은 화면이 아이콘으로 생깁니다. 설치는 1분이면 끝나요.

  1. Safari에서 이 페이지를 연 상태인지 확인하세요.카톡·네이버 앱 안이라면 위 안내대로 Safari로 다시 열어 주세요.
  2. 아래 「앱 화면 열기」 버튼을 누르세요.앱 첫 화면이 Safari에서 열립니다.
  3. 화면 아래쪽 버튼을 누르고 공유를 누르세요.공유 버튼 가 바로 보이면 그 버튼을 누르면 됩니다.
  4. 목록을 아래로 내려 홈 화면에 추가를 누르세요.안 보이면 더 보기를 누르면 나옵니다.
  5. 웹 앱으로 열기가 보이면 켜 둔 채로 오른쪽 위 「추가」를 누르세요.
  6. 홈 화면에 생긴 우리동네 입시연구소 아이콘으로 열면 끝!
