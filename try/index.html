숭실대 2026 자연 [문제 4]
배점 25점 권장 시간 25분 2027 시험일 11월 21일(토)

집합 A = {1, 2, 3, 4, 5, 6}에서 자기 자신으로 가는 함수 f : A → A 가운데, 아래 두 조건을 모두 만족하는 함수의 개수를 구하는 문제입니다.

  • 모든 x에 대해 f(f(x)) = f(x)
  • 모든 x에 대해 f(x) ≤ 3

답만 맞히는 문제가 아닙니다. 왜 그렇게 나누어 세는지를 답안에 써야 점수가 나옵니다.

문항은 조건만 요약해 소개했습니다. 제시문이 포함된 원문은 숭실대 입학처 → 입학전형안내 → 수시 → 기출문제의 2026학년도 자료에서 받으세요. 숭실대 입학처 열기 문항 원문의 저작권은 숭실대학교에 있습니다.

이렇게 참여하세요

  1. 25분을 재고 직접 써 보세요

    해설이나 답을 보지 않고, 시험장처럼 풀이 과정을 처음부터 끝까지 답안지에 써 주세요.

  2. 답안을 사진으로 찍어 주세요

    답안지 한 면이 사진 한 장에 다 들어가게, 위에서 똑바로 찍어 주세요(그림자·기울어짐 없이). 여러 장이면 순서대로 보내 주세요.

  3. 1:1 문의로 보내 주세요

    아래 버튼을 누르면 우리동네 입시연구소와 1:1 대화가 열립니다.

  4. 첨삭을 받아 보세요

    답안 위에 빨간 펜으로 표시한 첨삭본을 같은 대화방으로 보내 드립니다. 보통 하루 안에 돌려드립니다.
